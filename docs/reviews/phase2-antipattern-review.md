# Phase 2 anti-pattern review

Reviewed 2026-11-18 by `/root/pricing_model_code_review` alongside the [final code-quality review](phase2-final-quality-review.md). **PASS for the current local Phase 2 scope. No unresolved anti-pattern requires a change to frozen runtime files.** This is a code/contract review, not execution or publication approval.

The review found the following controls in the implementation and retained evidence:

- **No fitted-result substitution.** Synthetic unit/replay tests are identified as no-fit checks. The retained systemd infrastructure probe and real backend smoke have separate purposes. No synthetic test is presented as measured model quality or production capacity.
- **No hidden target leakage or retrospective feature tuning.** Origin histories and catalog membership are frozen point in time. Selection uses the declared origins and common observed-target masks. The failed v1 optimizer attempt prompted a declared computational lineage change, while the feature representation, alphas, objective, metrics, and selection rules remained unchanged.
- **No relabeling failed work as success.** Failed v1 evidence and the superseded first v2 proposal/source bytes are preserved. Failure reporting has no ranking, consumers require a complete run, and retries use new immutable run IDs. The corrected CLI cannot announce completion from a failed validation result.
- **No price-response overclaim.** The tree is a forecasting comparator. Poisson coefficients are shared conditional associations, not causal store-level effects. Qualification screens are not confidence intervals. Missing or unsupported scenario combinations remain unqualified; recorded sales are not silently treated as latent demand or stock availability.
- **No silent pricing enablement.** Model predictions and pricing eligibility are distinct. Scenario eligibility defaults false, and later consumers must apply qualification AND marginal support AND joint support. A usable prediction alone grants no pricing permission.
- **No approval manufactured by an identity flag.** Preparation, external review, authorization-stop, and fresh execute-only review are separate stages. This review writes no approval JSON and does not turn an earlier scope into permission for a later phase.
- **No accidental application import training.** Fitting is explicit in the governed worker, after a durable reservation. Imports, preparation, authorization, and default synthetic tests do not invoke a real fit. The CLI is a small local CPU workflow; it does not pretend to be the future hosted job system.
- **No aggregate resource proof replaced by worker self-report.** The retained outer service evidence, complete-worker cgroup peak, bounded deadlines, stale-progress check, and release evidence are reconciled. Internal samples remain diagnostic rather than substitutes for the outer capacity gate.
- **No erased provenance after development advances.** Historical replay checks saved identities and original decision times without requiring current Git/module/environment discovery. New training remains separately provenance-bound. Later code must preserve replay/serialization compatibility rather than rewrite historical manifests.
- **No executable upload path.** Local joblib checkpoints are private, authenticated artifacts. The future backend contract does not permit users to upload executable model objects.

One documentation trap was corrected in the unbound v2 runbook: result consumers must use `require_complete_run` or check `validate_run`'s returned status, since structured failure reporting is intentionally non-throwing. No bound file changed.

This review deliberately does not demand new frameworks, generic model registries, speculative abstractions, additional candidates, broader training, or unplanned tests. The frozen two-backend research implementation remains appropriately bounded. The current server/UI is not claimed to consume the new artifacts yet; that later integration must honor the documented identities and eligibility conjunction. Actual confirmation/refit outcomes still require independent review before Phase 2 is represented as scientifically verified or committed as complete.
